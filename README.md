**本程序保证“纯净”和“无毒”，不会释放垃圾缓存文件或者在注册表中主动创建垃圾条目。**  
**本程序的设计旨在修复感染银狐病毒的 Windows 电脑。**

本程序专治：

1. 任务管理器里有恶意进程却关不掉，定位到原位置提示文件夹为空；
2. 每隔一段时间进程复活，电脑性能被严重拖慢，CPU 被病毒霸占；
3. 微信、QQ 账号被盗，最近不知道为什么朋友说你搞诈骗刷单；
4. 有顽固的病毒文件无法删除，提示拒绝访问，权限不足或者已被打开；
5. 杀毒软件被 Windows Defender 应用控制禁止，无法打开等情况。

本程序特色：

1. **一键扫描，操作简单**。你只需要输入一个字母 C 并回车，程序会立即开始一键查杀银狐病毒，整个流程大概**两三分钟**。不需要你敲命令行，只需要静静等候程序完成杀毒！
2. **专治银狐，解救杀软**。银狐病毒会禁用杀毒软件，本程序可以立即击杀异常的银狐病毒进程，并删除掉你删不掉的病毒文件，接下来所有的任务交给那不忘初心的杀毒软件。
3. **兼容性强，不怕不行**。本程序支持解救 Windows 7 或更高版本的感染银狐的电脑，并且还有以下的方案应对恶性的银狐病毒。

第 3 条所说的方案如下：


### 终末 1 - 程序打不开怎么办

如果打不开清除脚本，或者闪退，你可以试试以下操作。

第一阶段：

请你尝试将杀毒程序复制到另一个位置，并随便改一个“人畜无害”的名称，后缀改为 .com。  
然后打开新的文件，估计没有问题了。

第二阶段：

如果第一阶段不行，你试试把后缀改成 .scr，然后再次打开。

第三阶段：

打开系统配置（msconfig）的引导选项卡，勾选安全引导再重启，进入安全模式去进行杀毒。  
杀完后取消勾选安全引导重启回正常系统，然后再在正常系统运行第二阶段复制出来的 .scr 文件。  
安全模式中没有病毒自启动，可能侦测不到，效果可能减弱，因此在正常系统中复查是必须操作。  


### 终末 2 - 怎么让银狐直爆炸

如果你能打开 Windows 安全中心，且安全中心没有被禁用，你可以试试在“病毒和威胁防护”的“管理设置”中，看一下“排除项”。  
估计那里就有病毒给自己创建的信任条目，你把所有不是自己创建的排除项全部给删除掉，然后看看 Windows 安全中心会不会马上报毒。

然后，你还可以试试去控制面板或者本地安全策略重新打开被病毒关闭的用户账户控制（UAC），待会有些病毒想要自启动还得经过你同意。
